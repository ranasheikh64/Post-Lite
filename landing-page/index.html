Real-Time Core

First-Class Socket.IO & WebSocket Tooling

Most API clients treat real-time protocols as an afterthought. Jronix Post was architected from the ground up to give Socket.IO and WebSockets full protocol parity.

Named Socket.IO Events & Ack

Register specific events (chat_message, order_update) in our dedicated Events Grid. Enable server acknowledgements with a single switch and receive response payloads in real-time.

  • Dynamic event add/remove without losing context
  • Custom acknowledge callbacks with timeout safety
  • Message counters per event channel

Live Duplex Frame Inspector

Monitor incoming and outgoing WebSocket frames side by side with microsecond timestamping, color-coded direction badges, search filtering, and one-click JSON tree formatting.

  • Auto-reconnection on connection drops
  • Binary & text frame decoding
  • Clear stream or export frame history with one click

One-Click Beautifier & Shortcuts

Tired of unformatted JSON payload strings? Hit our instant Beautify button or press Cmd + / (or Ctrl + /) to toggle line comments without breaking your payload.

  • Smart selection boundary detection
  • Syntax highlighting with active variable pill rendering
  • Error indicator on invalid JSON schemas

Handshake Auth & Query Tokens

Secure WebSockets and Socket.IO servers require custom headers, cookies, and query tickets. Configure custom handshake headers and query params seamlessly in our dark table view.

  • Dynamic variable interpolation like Bearer {{jwt_token}}
  • Persistent connection state across tabs
  • Custom paths (e.g. /socket.io/v2, /ws/feed)
